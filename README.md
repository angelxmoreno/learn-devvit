# Learn Devvit: Complete Course for TypeScript Developers

Welcome to the complete Devvit learning curriculum! This course is designed for TypeScript developers who want to master Reddit's Developer Platform.

## What is Devvit?

Devvit is Reddit's official developer platform that allows you to build applications that run directly on Reddit. With Devvit, you can create custom experiences, automate moderation, build interactive features, and extend Reddit's functionality.

## Course Structure

This course is organized into 13 comprehensive lessons that will take you from beginner to production-ready Devvit developer.

## Prerequisites

Before starting this course, you should have:

- **Strong TypeScript knowledge** - Understanding of types, interfaces, async/await, and modern TS features
- **Basic Reddit familiarity** - Understanding of Reddit's structure (subreddits, posts, comments, etc.)
- **Command line comfort** - Ability to use terminal/command prompt
- **Git basics** - For version control (recommended)

## Estimated Time

- **Total course time**: 24-27 hours
- **Recommended pace**: 2-3 lessons per week
- **Expected completion**: 5-7 weeks
